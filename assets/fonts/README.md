# Fonts

This directory contains the project's local fonts.

The font files are commercially licensed and are intentionally excluded
from version control.

To run the project locally, place the required font files in this directory.

## Required Fonts

- IRANYekan
  - Regular
  - Medium
  - Bold
  - Extra Bold
  - Extra Black
  - Black
  - Light
  - Thin
